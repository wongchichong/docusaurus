# `@docusaurus/types` (Woby Adapted)

Common types for Docusaurus packages, adapted for a Woby.js based Docusaurus system.

**Note:** As part of a migration/conversion process towards the Woby framework, React-specific types (e.g., from `react`, `@types/react`) and types related to `react-helmet-async` have been removed or replaced within these type definitions. The types are now intended for use in a Docusaurus environment where Woby is the rendering framework.
