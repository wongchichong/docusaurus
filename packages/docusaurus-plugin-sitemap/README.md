# `@docusaurus/plugin-sitemap` (Woby Compatible)

Sitemap generation plugin for Docusaurus, compatible with Woby.js based sites.

This plugin generates a sitemap.xml file based on the routes and site configuration of your Docusaurus site. Its operation is framework-agnostic, relying on Docusaurus core data structures rather than specific UI framework details.

## Usage

See [plugin-sitemap documentation](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-sitemap).

**Note for Woby.js Users:** This plugin has been updated to remove direct React peer dependencies. It should function correctly in a Docusaurus environment adapted for Woby.js.
