# `@docusaurus/eslint-plugin`

ESLint plugin, originally to enforce best Docusaurus (React-based) practices.

**Note for Woby Conversion:** As part of a migration/conversion process towards the Woby framework, all Docusaurus-specific (and therefore React-specific) rules within this plugin have been disabled. The plugin configurations (`recommended`, `all`) are now empty and the plugin effectively performs no operations. This package is marked as deprecated in its `package.json`.

## Original Usage

See [eslint-plugin documentation](https://docusaurus.io/docs/api/misc/@docusaurus/eslint-plugin).
